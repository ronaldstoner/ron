Standard gamepad

Connect your controller and press a button with the game page focused. Browser-standard Xbox-style and PlayStation-style layouts use the same button positions. Device and browser support can vary; keyboard controls remain available. One controller routes to NES Player 1.

Use the on-screen PAUSE button or Escape to pause emulation. HELP explains the controls during play. If a browser has not enabled audio, click SOUND.

Saves and privacy

Battery saves use this browser's local storage when available. SAVE STATE downloads a JSON save; LOAD STATE restores it with the same ROM. Saves do not sync between browsers or computers. The game includes no analytics, CDN scripts, account system, ROM uploader, or external runtime dependency.

Original Tecmo, new perspective

The supplied ROM runs its original menus, football rules, roster data, music, and sound in JSNES. A new camera projects its original field and sprite pixels. The NFL shield, TECMO logos, yard numbers, end zones, and crowd come from that loaded file. The extra HUD, focus arrow, and optional field guides are presentation aids.

This is a playable experimental conversion. Players remain flat pixel sprites. Some jump and dive poses retain original side-view art, and missing front/rear three-point stances use original standing sprites. Full-season play and every special-teams situation have not been audited.
